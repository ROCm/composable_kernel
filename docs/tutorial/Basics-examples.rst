CK Basics

The Composable Kernel library includes examples of how to implement basic operations using CK Tile.

        Demonstrates the basic setup required to write a kernel.

    `Permute <https://github.com/ROCm/composable_kernel/blob/develop/example/ck_tile/06_permute/README.md>`_
        Generic permute kernel example.

    `Batched transpose <https://github.com/ROCm/composable_kernel/blob/develop/example/ck_tile/35_batched_transpose/README.md>`_
